# 🚀 Portfolio de Ibrahima Sory Diallo

Un portfolio exceptionnel conçu pour démontrer l'excellence technique, l'innovation et une identité visuelle forte. Ce projet reflète l'expertise d'un développeur Full-Stack sénégalais tourné vers l'international.

![Preview](/public/og-image.jpg)

## ✨ Concepts Clés : "Tech Meets African Innovation"

Ce portfolio allie la modernité technologique internationale (Stripe-like clarity, Linear-like animations) à une identité visuelle subtilement inspirée du Sénégal ("Premium Sénégal").

### 🎨 Design & Expérience
- **Animations Premium** : Micro-interactions fluides développées avec Framer Motion.
- **Design Système** : Palette "Premium Sénégal" (Vert profond, Or, Rouge énergique) sur un fond Slate moderne.
- **Performance** : Score Lighthouse visé de 95+ grâce aux optimisations Next.js.
- **Responsive** : Expérience fluide du mobile au desktop avec un menu mobile sur mesure.

## 💻 Installation Locale

1. **Cloner le projet**
   ```bash
   git clone https://github.com/[votre-pseudo]/modern-portfolio-ibrahima.git
   cd modern-portfolio-ibrahima
   ```

2. **Installer les dépendances**
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement**
   ```bash
   npm run dev
   ```

4. **Build pour la production**
   ```bash
   npm run build
   ```
